# gitagent-demo

A sample repository used to demonstrate GitAgent's AI-powered code analysis capabilities.

## Purpose

This repo contains intentional bugs, security vulnerabilities, and technical debt to showcase how GitAgent identifies and reports issues across a codebase.

## Issues Present

- SQL injection vulnerabilities
- Hardcoded credentials and secrets
- Missing error handling
- Plain text password storage
- No JWT expiration
- Inefficient algorithms
- Dead/unused code
